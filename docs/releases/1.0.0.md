## Android companion candidate

The companion uses a dark interface throughout, including dialogs, inputs and Android system bars. It manages projects, tasks, version plans and notes on the phone without requiring source folders or a localhost server. It reads public GitHub issues and completed commits, with meaningful-change, file and function filters. GitHub issues remain read-only. Cached work and local tasks/notes work offline.

Transfer is manual JSON backup/restore. Desktop task exports can seed the companion, preserving completed status and target versions; the existing desktop export does not include notes or repository URLs. Companion backups cannot yet be imported into the desktop app, and automatic desktop-to-phone synchronization is not available. Do not replace the desktop database with a companion backup.

Android APK signing uses a stable self-generated key without a paid store account. Keep the private signing key and password backed up: future Android updates must use the same key. Keys are excluded from git and stored as encrypted CI secrets.

## Features

- Polished native desktop workspace with working project registration and folder selection.
- Project pages with file browsing, read-only source previews, and a README below the files.
- Completed-work history from GitHub with feature, fix, module, file, function, and author filters.
- Planned work combines local tasks and open GitHub issues, with numeric version grouping and prerelease versions.
- Clickable project tags show every project with the exact tag, including archived projects.
- Tasks, subtasks, notes, time tracking, reports, and optional Git-based data synchronization.

## Installation and compatibility

The desktop interface is bundled; no localhost server is required. Windows uses the system WebView2 runtime; its installer can download the runtime when needed. Linux packages require a compatible WebKitGTK 4.1 environment. Use the package for your architecture.

Desktop builds currently have no publisher code-signing certificates. Windows may show an unknown-publisher prompt; macOS builds are not notarized. iOS device installation requires Apple signing and provisioning and cannot be provided as a generic unsigned executable.

GitHub history and issue synchronization use the optional GitHub CLI: install `gh` and run `gh auth login`. Local tasks, files, notes, and Git history work offline. GitHub issues remain read-only in DevTrack and link back to GitHub for editing.

Existing task data is preserved. Tasks without a target version appear as Unscheduled. Back up your database before upgrading: this release adds a task-version column.
